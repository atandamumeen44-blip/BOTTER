🎯 The 99.9% Simulation Promise

How we guarantee near‑zero wasted gas.

Pre‑Flight Checklist (every trade, every time) 1. Mempool check – is a large swap about to land that will kill this spread? If yes, skip. 2. Multi‑RPC consensus – fetch reserves from 2 different RPCs. If they disagree by >0.05%, skip. 3. Liquidity deep enough? – pool TVL must be ≥ $100k. Compute exact slippage from AMM formula. 4. Gas ceiling – if current base fee + priority fee > 500 Gwei, skip. 5. Dynamic profit threshold – minimum profit adapts to wallet balance (see Safety section). 6. Safety margin – an extra $0.30 is subtracted from net profit before decision. 7. eth_call simulation – the entire flash‑loan transaction is executed locally. We read the actual USDC balance change. If it's less than expected (or negative), skip. 8. Only then – sign and send via Flashbots Protect. Result: Failed transactions drop to near zero. Gas budget lasts 10x longer.

🚀 Deployment (Oracle Cloud Free)

One VM, one binary, forever free.

1. Deploy Flash‑Loan Contract

One‑time on Polygon (~$0.50 gas). Aave V3 receiver with swap logic.

2. Compile Rust Binary

`cargo build --release`. Upload to Oracle VM.

3. Set Environment Variables

PRIVATE_KEY, RPC_URLS, CONTRACT_ADDRESS, MIN_PROFIT, etc.

4. Run & Monitor

`./sharklet` starts hunting. Dashboard on port 8080. Telegram alerts active.
